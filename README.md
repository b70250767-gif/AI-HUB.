# AI HUB — Android starter

Первый этап проекта: тёмный интерфейс чата и переключение между ChatGPT, DeepSeek и Claude.

## Что уже работает
- Android-приложение на Kotlin + Jetpack Compose.
- Переключение между тремя моделями.
- Демонстрационная переписка и поле ввода.
- GitHub Actions для сборки debug APK.

## Что пока не подключено
Сейчас это интерфейс-предпросмотр. Реальные ответы моделей появятся после подключения серверного API.

## Сборка через GitHub на телефоне
1. Создай новый пустой репозиторий GitHub.
2. Распакуй архив и загрузи всё содержимое проекта в корень репозитория.
3. Назови основную ветку `main`.
4. Открой вкладку **Actions**.
5. Выбери **Build AI HUB APK** и нажми **Run workflow** (или дождись автоматической сборки после push).
6. Открой завершённый запуск и скачай артефакт **AI-HUB-debug-apk**.
7. Распакуй скачанный ZIP — внутри будет `app-debug.apk`.

## Требования
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK 35

## Безопасность ключей
Не добавляй API-ключи OpenAI, DeepSeek или Anthropic в Kotlin-код, GitHub-репозиторий или APK. Следующий этап — отдельный backend, который хранит ключи в переменных окружения и принимает запросы от приложения.
